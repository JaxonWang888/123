# V27 零件序号与 BOM 明细表

新增直径10 mm的零件序号圆，数字高度5 mm，采用水平、竖直居中对齐；按图纸比例换算模型尺寸。箭头指向相应零件，圆圈、数字自动避让图形、尺寸和注释，引线优先直线，必要时折线绕行；没有合适位置时提示调整纸张或比例。

按提供的“BOM表模板.dwg”中*T167表格的列宽、分栏与底部表头重建原生线条及文字，随明细行数向上扩展。普通零件代号、图号/标准号和材料固定填写“***”，属性ZD、备注See This DWG.，质量留空。接地板保留代号93201-2406362、标准ASME-EB-04、材料SA-240 316/316L、属性ZD、备注通用图/General、单重0.16 kg与总重0.32 kg；这两个质量值按提供图片固定保留，不随接地板尺寸变化。

数量按固定、滑动两个鞍座的实际零件汇总。内筋板按实际形状合并，不同形状分别列行；中置腹板两侧为独立板件，侧置腹板为整块筋板。序号随分组动态变化，外筋板、接地板顺延，图中标注和明细表始终共用编号。

BOM默认排在图纸右上空白区域，A2及以上保持模板尺寸；A3/A4按纸宽缩小表格。自动推荐比例为BOM预留空间，序号圆和数字仍保持10/5 mm。模板来源与提取的表格记录见reference/bom-template.json；不导入模板中与本任务无关的块。

## 使用

Windows x64离线程序，无需安装Python。主图采用毫米1:1模型，可编辑DWG/DXF和黑白矢量PDF。新增功能自动生效，无需增加输入项。接地板尺寸及独立详图比例仍可编辑，参数文件版本V8保持兼容。

原始DWG/DXF标注样式为HM 1-1，文字样式HM-ASME。勾选自动处理后，由本机AutoCAD打开DWG、整理标注为HM-ASME 1-1、旋转0、全局比例等于图纸比例，并保存；孔及设备间距实值文字保留。序号圆与数字属于普通图元，不受尺寸样式切换影响。
