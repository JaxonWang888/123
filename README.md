# V29 用AutoCAD原生TABLE命令新建BOM

BOM不再复制模板中的整张表格。程序调用AutoCAD内置TABLE命令打开“插入表格”窗口，选择“明细栏”样式及“从表格样式开始”，使用指定插入点，新表格插入后才按实际零件数增加明细行并填入数据。

插入窗口按截图设置：额外列0、额外行0，列宽显示50、行高显示14；保留标签单元文字、数据单元文字、单元样式替代，取消块、数据链接、字段和公式，启用预览。上述14为插入窗口设置，新增明细行按用户确认保持8 mm。字号、左右边距2、名称及规格数据单元格左中对齐、数量与动态编号等既有要求保持。

当前图纸没有“明细栏”样式时，才从内置样式来源补入AcDbTableStyle及其样式依赖；不会复制原模型表格，且检查补入样式前后模型对象数量不变。BOM本体必须由TABLE命令新建并检查StyleName为“明细栏”，不以AddTable接口或线框文字替代TABLE命令。

原生TABLE对话框仅在本次AutoCAD进程及已启动的建表任务中自动设置，使用窗口控件消息，不发送全局鼠标或键盘输入。未知窗口、选项不可用、样式或表头不符时停止并记录日志，不会假报完成。明细行数据按已有规则填写：普通代号/图号/材料***、普通质量空白，接地板固定资料和0.16/0.32 kg保留；原有序号就近排布及接地板70文字避让保持。

## 下载与使用

- [V29程序](releases/saddle-generator-v29.exe)
- [完整离线包](releases/saddle-offline-v29.zip)
- [完整对应源码](releases/saddle-source-v29.zip)
- [排布预览](releases/drawing-v29.png)

Windows x64程序，运行无需Python。DWG/DXF导出均需本机AutoCAD/Mechanical2018执行TABLE及保存；等待状态栏确认处理完成。取消“同时整理尺寸”只跳过尺寸样式整理，BOM仍通过TABLE创建。

旁边的“.BOM数据”文件用于自动填表与重试。成功保存后的CAD文件含自有的AcDbTable及明细栏样式，不依赖外部模板或数据文件。包内DWG/DXF是离线基础样例，需在安装AutoCAD2018的Windows电脑上运行“完成样例原生BOM.cmd”后才具有原生BOM。PDF/PNG为排布缓存预览，不是TABLE实机执行证据。

当前环境没有AutoCAD Mechanical2018。TABLE命令、对话框及填表流程已做Windows模拟检查，尚需实机核验原生窗口、样式依赖、插入及保存。原有模型、尺寸、序号、PDF和基础CAD导出另有回归检查，详见验证报告。

主图毫米1:1模型。基础标注样式HM 1-1、文字样式HM-ASME；勾选整理时改为HM-ASME 1-1、文字旋转0、全局比例随图纸。参数文件V8保持兼容。原生表格结果保存为2013格式，可由Mechanical2018读取。默认参数仅供演示，不进行强度计算。

程序及GNU LibreDWG遵循GPL-3.0-or-later，许可证和完整对应源码随包提供。离线源码构建需要Zig0.13、CMake及Python3；EXE运行不需要这些构建工具。
