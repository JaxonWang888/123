# V28 原模板BOM与序号排布优化

1. 腹板序号选取相邻筋板之间的空档，并限制在本鞍座附近寻找位置，避免跨到断开线附近。
2. 接地板序号指向详图右侧直边，不再与圆角标注箭头相对；引线可跨越70尺寸线，但会避让70文字。
3. DWG/DXF不再写入重绘的BOM线条和文字。AutoCAD2018自动处理阶段从内置原始“BOM表模板.dwg”复制E841F原生AcDbTable，保留表头、合并单元格和表格样式，仅扩展数据行及填写数据。禁止退回AddTable新建表或线框重绘。
4. “名称及规格”列在表头上方的数据单元格设为左中（acMiddleLeft）。原生表格水平边距及单元格左、右边距的CAD属性值均设为2，保存前回读核对。普通字段仍为***，普通质量留空；接地板资料、质量和按实际形状动态编号规则保持。

DWG/DXF导出均需要本机AutoCAD/Mechanical2018完成原生BOM复制。勾选“同时整理尺寸样式”时还会整理为HM-ASME 1-1、旋转0、全局比例随图纸；取消勾选仍会复制BOM。复制或属性验证失败会提示未完成，保留基础图纸和备份，不以线框表格替代。

程序内置原始模板，无需手动选择。图纸旁的“.BOM数据”文件用于自动填表与失败重试；成功保存后的DWG内含原生表格，不依赖模板或数据文件。界面及PDF是排布预览，使用表格显示缓存；离线库不能解码模板中的原生表格，最终CAD表格必须由AutoCAD完成。

## 下载与使用

- [完整离线包](releases/saddle-offline-v28.zip)
- [完整对应源码](releases/saddle-source-v28.zip)
- [排布预览](releases/drawing-v28.png)

Windows x64程序，运行无需Python。打开程序输入参数后导出，等待AutoCAD提示处理完成再使用图纸。包内CAD样例是离线基础导出，尚无原生BOM；在安装AutoCAD2018的Windows电脑上运行“完成样例原生BOM.cmd”后生成完整表格。不要将未完成自动处理的基础样例视为最终图纸。

本环境没有AutoCAD Mechanical2018，真实模板恢复、跨文档复制、重生成和保存尚需实机核验；已使用Windows COM模拟核对原对象复制、合并表头保留、行增删、左中对齐、边距2、重复处理与失败行为。原有尺寸、结构、接地板、序号与黑白矢量PDF另有模型及导出回读检查，结果在包内报告。

主图毫米1:1模型；离线基础标注样式HM 1-1、文字样式HM-ASME，原生表格经AutoCAD保存为2013格式，Mechanical2018可读取。参数文件V8保持兼容。默认参数仅供演示，不进行强度计算。程序与GNU LibreDWG遵循GPL-3.0-or-later，完整源码和许可证随包提供。源代码离线构建需要Zig0.13、CMake及Python3；运行EXE不需要这些构建工具。
