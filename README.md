## 本次累计更新

- 每种不同长度的筋板至少标注一处厚度；同长度对称件不重复标注。默认件号5、6、7均覆盖。
- 修复旋转尺寸读取 ExtLine1Point 报错，改为校验句柄后读取实体 DXF 13/14 定义点。
- 腹板厚度尺寸避开筋板和孔行；右侧接地板位置尺寸数字移至右侧。
- 在样式、数字位置和重生成完成后，最后补写并校验原生公差。
- 更新明细栏模板及单元格边距、对齐，保留全部累计业务约束。

## 使用与约束

用 V36 重新导出 DWG/DXF，保留自动生成的 `.BOM数据` 和 `.标注数据`，等待自动整理完成。失败时保留原始备份和日志，不自动确认未知提示。

BOM 必须通过 AutoCAD 原生 TABLE 命令、明细栏样式新建，插入后增行填写；明细行高8mm。不得复制模板整表，不使用 AddTable 或线框替代。名称及规格明细格左右边距2×图纸比例、左中对齐；其他明细格水平及垂直边距1×图纸比例、正中对齐；表头及标题保留模板边距、正中对齐。
